# Передача проекта в новый чат

Модуль бронирования для усадеб. Демо работает на реальных данных конной усадьбы «Буцевичи» (verhom.by).
Подробности о продукте и запуске — в README.md.

## Как запустить

- PostgreSQL: Postgres.app на порту **5433**, пользователь `postgres` без пароля.
  - рабочая база `usadba_dev`;
  - тестовая база `usadba_test`.
- `npm run dev` → http://localhost:4195. Главная сразу открывает `/u/butsevichi`.
- Вход в панель: кнопка «Открыть демо» на `/login` или `demo@gurtom.by` / `demo`.
- `npm run db:seed` пересоздаёт демо-данные. У усадьбы и администратора постоянные id, поэтому открытая сессия не ломается.
- Тесты: `npm test` — расчёт цены и iCal, `npm run test:int` — серверный код против базы `usadba_test`.

## Что сделано

1. **Код друга (WebSofa2) взят как основа.** История очищена, мебельный магазин удалён. Стек: Next.js 16, Prisma, PostgreSQL, Tailwind 4.
2. **Первая версия отвергнута.** Это была CRM для выдуманной базы отдыха с КП и «скинуться компанией». Код остался в коммите `b0f36af`, из интерфейса убран.
3. **Текущая версия — универсальный модуль бронирования на данных Буцевичей:**
   - **Страница для гостя** в стиле их первого демо (хвоя, лён, латунь, Cormorant + Manrope):
     - фото домов в арке и цены по дням;
     - календарь с ценой ночи под каждой датой и зачёркнутыми занятыми днями;
     - расчёт стоимости и задатка 40%;
     - заявка;
     - встраиваемая форма `/embed.js`.
   - **Расчёт** (`lib/quote.ts`):
     - тарифы по дням недели и праздникам;
     - тариф для небольшой компании с окном бронирования 14 дней;
     - доплата за гостей сверх базы;
     - скидка 10% с третьей ночи;
     - услуги с количеством.
   - **Панель:**
     - заявки (вкладки, сводка, карточка, история, статусы);
     - календарь обоих домов;
     - дома и тарифы (фото, редактор тарифов, проверка расчёта);
     - услуги;
     - тексты, фото и праздники;
     - настройки (показ занятости и цены, задаток, Telegram, синхронизация iCal, код для вставки).
4. **Техническая проверка (последний этап):**
   - **Баг: панель падала, если сессия ссылалась на удалённого пользователя** (после пересоздания базы). Теперь `requireSession` сверяет сессию с базой и при устаревшем входе ведёт на `/logout` → `/login`.
   - **Баг: фото больше 1 МБ не загружались** из-за лимита server actions. Лимит поднят до 12 МБ в `next.config.ts`, фото отправляются по одному.
   - **Баг: deadlock при одновременном подтверждении одних дат.** Двойной брони не было, но второй администратор получал ошибку сервера. Теперь подтверждения по одному дому идут в очередь через `pg_advisory_xact_lock`. Тест прогнан 15 раз подряд — стабильно.
   - **Добавлены 69 интеграционных тестов** (`tests/int`):
     - форма бронирования: сохранение и проверки;
     - все действия панели: что пишется в базу, фото на диске, ленты Куфара и Реалта, каскадное удаление;
     - безопасность: вход, поддельный и устаревший токен, изоляция усадеб, iCal без имён гостей, выход за папку загрузок.
